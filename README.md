# Практическая работа №10. Цикл foreach и массивы

## Цель работы
Изучить принципы объявления и инициализации массивов в языке C#, освоить применение специализированного цикла `foreach` для последовательного перебора элементов коллекций и символов строк, а также понять ключевые отличия и ограничения `foreach` по сравнению с классическим индексным циклом `for`.

## ПР10. Ответы на контрольные вопросы

### 1. В чём главное преимущество цикла foreach перед циклом for при простом чтении данных?
Главное преимущество цикла `foreach` заключается в его синтаксической компактности, лаконичности и высокой читаемости. Нам не требуется вручную заводить переменную-индекс (например, `int i = 0`), следить за условием выхода (`i < array.Length`) и принудительно увеличивать счётчик на каждой итерации (`i++`). Программа сама автоматически и безопасно перебирает коллекцию от первого до последнего элемента (как это сделано при подсчёте суммы баллов, выводе дней недели в Задаче Б или расчёте средней температуры в Варианте 1). Это полностью исключает случайную ошибку выхода за границы массива.

### 2. Какое главное системное ограничение есть у цикла foreach? Что произойдёт, если попробовать изменить элемент внутри тела?
Главное ограничение заключается в том, что переменная итерации цикла `foreach` открыта исключительно для чтения (read-only). Среда .NET физически запрещает изменять значения элементов коллекции через эту переменную напрямую (например, написать `point = point + 5`). При попытке принудительно перезаписать данные внутри тела `foreach` компилятор Roslyn выдаст критическую ошибку сборки на этапе компиляции и заблокирует запуск программы.

### 3. В каких ситуациях без классического цикла for с индексатором физически невозможно обойтись?
Классический цикл `for` незаменим в двух основных сценариях:
1. Когда элементы исходного массива необходимо перезаписать, обновить или модифицировать прямо на их позициях. В коде это наглядно доказано в блоке увеличения очков, где для изменения значений мы обращаемся к ячейкам массива по их точному индексу: `points[i] = points[i] + 5`.
2. Когда логика программы жёстко завязана на номера элементов (индексы) — например, если требуется выводить элементы через один, обрабатывать строго чётные позиции, менять порядок обхода или одновременно двигаться по двум разным массивам одинаковой длины.
